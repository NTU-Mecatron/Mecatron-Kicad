# Mecatron Kicad
This repository contains a KiCad PCM library for Mecatron's custom KiCad footprints, and their attached symbols and 3d-Models.

## Contents

- `footprints/` – KiCad PCB footprints
- `symbols/` – KiCad schematic symbols
- `3dmodels/` – 3D models associated with footprints
- `resources/` – Images and other PCM resources
- `metadata.json` – KiCad PCM package metadata
- `pcm/` – PCM repository metadata
- `dist/` – Generated release packages
